# Dobrota.save
Безопасная (Clean) версия шуточного вируса Dobrota.exe. Программа устраивает контролируемый хаос на экране (GDI-эффекты, всплывающие окна), но абсолютно безвредна для Windows, не удаляет файлы и сделана ради веселья. Идеально для тестов в песочнице. Огромное спасибо за помощь в создании/тестировании: @stickmyrzik-bit
